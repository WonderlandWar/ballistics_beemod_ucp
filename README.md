# Portal: Ballistics BEEMod UCP

This BEEMod UCP ports and improves the new elements that were introduced in [Portal: Ballistics](https://www.moddb.com/mods/portal-ballistics), a Portal mod focused on using turrets as testing elements.

# Added Items
#### Persistent Target 
- Sends an output while it's being shot at by anything bullet based, but stops sending an output once it's no longer being shot at.
- Turrets prioritize shooting Persistent Targets over players.

#### Target Cube
- A cube that turrets shoot at.
- Turrets will prioritize shooting Target Cubes over players and Persistent Targets.
  
#### Mounted Turret
- A player controlled gun that causes high knockback to physics based objects
- Has the ability to activate a Persistent Target.

#### Ballistics Turret
- A modified Turret that deploys and retracts significantly quicker
- Has the ability to consistently keep Persistent Targets active regardless even if some of its bullets miss
- Has a fix that prevents an exploit that allows you to hold a turret that can also target and shoot things.
#### Ballistics Turret Dropper
- Functions identically to the Turret Dropper, but drops Ballistics Turrets instead.

# Known Issues
- Turret Priorities don't work properly in cooperative.
- Mounted Turret has various minor bugs with its visuals and aiming in cooperative.
